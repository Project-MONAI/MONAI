# LPIPS calibration weights

These are the unmodified LPIPS v0.1 linear calibration weights from
[richzhang/PerceptualSimilarity](https://github.com/richzhang/PerceptualSimilarity/tree/082bb24f84c091ea94de2867d34c4544f68e0963/lpips/weights/v0.1),
commit `082bb24f84c091ea94de2867d34c4544f68e0963`.
The copyright notice, redistribution conditions, and disclaimer are in
[LICENSE.LPIPS](LICENSE.LPIPS).

These small calibration layers are separate from the ImageNet feature networks,
whose pretrained weights are provided by Torchvision.
